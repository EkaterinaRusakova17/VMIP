# Анализ проекта

## Нарушение SRP

### main()

Функция выполняет слишком много задач:

- парсинг аргументов командной строки
- аутентификация пользователя
- валидация ресурса
- проверка прав доступа
- обработка ошибок

Исправление: разделить на отдельные классы с четкими обязанностями.

### Resource

Класс отвечает и за хранение данных, и за поиск по пути, и за получение дочерних элементов.

Исправление: нужно вынести логику поиска в отдельный сервис.
